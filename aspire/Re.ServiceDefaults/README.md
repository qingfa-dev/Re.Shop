# Re.ServiceDefaults

Shared host concerns for the API and admin — currently an empty assembly. _module · provider_

## Summary

This project is the Aspire "service defaults" library: the place where health
checks, standard resilience handlers, service discovery, and OpenTelemetry are
meant to be registered once and adopted by every host. Its package set declares
all of that intent — resilience, service discovery, and five OpenTelemetry
packages are referenced. **However, the source file that would define
`AddServiceDefaults` and `MapDefaultEndpoints` does not exist**, so the assembly
currently compiles to nothing and exposes no API.

## Boundaries

In scope:
- `AddServiceDefaults` / `MapDefaultEndpoints` — when they exist: health checks,
  resilience, service discovery, OpenTelemetry.
- Anything genuinely shared by more than one host.

Out of scope:
- Per-host composition → [`../../app/api/README.md`](../../app/api/README.md), [`../../app/admin/README.md`](../../app/admin/README.md).
- Orchestration → [`../Re.AppHost/README.md`](../Re.AppHost/README.md).
- Application or persistence logic → `../../src/`.

## Assumptions

- Both hosts already carry a `ProjectReference` to this project, so restoring
  and building succeed — an empty assembly is a valid reference target.
- **No host calls `AddServiceDefaults` or `MapDefaultEndpoints`**, because no
  such extension method exists yet. Do not assume `/health` or `/alive` are
  mapped.
- `GenerateDocumentationFile` is `false` for this folder: the root props comment
  explains it was disabled because the template file carried no XML comments.
  With `TreatWarningsAsErrors`, documenting this assembly before writing the
  code would fail the build on CS1591.
- Package versions come from the root `Directory.Packages.props`; this project
  declares none of its own.

## Invariants

- References no `Re.Shop.*` project at all — spec §5.3 rule 8, asserted by
  `ServiceDefaults_references_no_shop_project`.
- No host may assume `/health` or `/alive` are mapped until the defaults exist.

## Conventions

- When the defaults are restored, register them from `Program.cs` in each host
  rather than calling them implicitly from this library.
